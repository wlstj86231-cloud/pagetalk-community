# 페이지톡 MVP

웹툰·웹소설 이야기를 중심으로 한 정적 커뮤니티 프로토타입입니다. 작품 원문이나 유료 회차 이미지를 올리는 구조가 아니라, 감상·추천·토론·창작 이야기를 모으는 합법 커뮤니티 방향으로 설계했습니다.

## 실행

브라우저에서 `index.html`을 바로 열면 됩니다.

## 파일 구조

- `index.html`: 화면 뼈대와 스크립트 로딩 순서
- `styles.css`: 화면 디자인과 반응형 레이아웃
- `src/data.js`: 게시판, 샘플 게시글, 색상 팔레트
- `src/storage.js`: `localStorage` 저장과 불러오기
- `src/utils.js`: 시간 표시, HTML escape, 인기 점수 계산 같은 순수 함수
- `src/render.js`: 게시판, 목록, 상세 패널, 댓글을 화면에 그리는 코드
- `src/main.js`: 클릭, 입력, 글쓰기, 좋아요, 댓글 등록 같은 동작 연결

브라우저에서 파일을 바로 열 수 있게 ES module 대신 일반 스크립트 파일을 순서대로 불러옵니다.

## 포함된 기능

- 게시판 필터: 전체, 웹툰, 웹소설, 추천, 떡밥·토론, 창작방
- 검색과 인기·최신·댓글 정렬
- 글쓰기
- 게시글 좋아요, 저장, 신고 표시
- 댓글 작성과 댓글 좋아요
- 베스트댓글 자동 표시
- 스포일러 게시글 흐림 처리
- `localStorage` 저장
